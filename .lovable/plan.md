# DLFLY Overseas Website

## Scope
Build a responsive, multi-page overseas education consultancy website for DLFLY Overseas, inspired by the clear service navigation and lead-generation patterns of y-axis.com without copying its branding or content.

## Experience
- Create a polished homepage with prominent study-abroad imagery, destination discovery, service summaries, and clear enquiry/contact actions.
- Add dedicated pages for Study Abroad, Visa, Permanent Residency, Education Loans, About, and Contact.
- Use a shared header, footer, and enquiry links across pages; include +91 6304636998 and a footer backlink reading “Developed by Octaleads” to https://www.octaleads.com.
- Ensure layouts adapt to mobile and desktop and include page-specific titles and descriptions.

## Technical details
- Implement pages using the existing TanStack Start file-based routes and the current design system.
- Keep the site frontend-only; enquiry actions use the supplied phone number rather than adding data storage or backend services.
- Use original, project-local visual assets and shared presentation components; preserve every route's own metadata.
